# 📝 To-Do List App

A simple command-line to-do list application built with Python that helps you manage your daily tasks.

## 📖 How It Works
The program lets you add, view, complete, and delete tasks from your to-do list, all through a simple text-based menu.

## 🛠️ Built With
- Python 3

## 📌 Features
- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 📋 View all tasks
